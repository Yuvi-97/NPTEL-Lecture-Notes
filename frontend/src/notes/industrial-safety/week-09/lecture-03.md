# Week 9 – Lecture 3: Human Error Identification

## 1. Key Concepts
- **Human Error Identification (HEI):** Structured qualitative techniques used by safety engineers to anticipate and identify potential human errors before they lead to workplace incidents.
- **Hierarchical Task Analysis (HTA):** The foundational prerequisite for HEI, decomposing a complex job into hierarchical sub-goals, tasks, and elementary physical/cognitive operations.
- **SHERPA (Systematic Human Error Reduction and Prediction Approach):** A widely adopted HEI methodology developed by Embrey (1986) linking task classifications to specific error modes.

## 2. Important Points
- **Core Steps of the HEI Process:**
  1. Conduct Task Analysis (HTA) to map all operator steps.
  2. Select and apply an HEI taxonomy to each task step.
  3. Identify potential error modes and their root psychological causes.
  4. Assess consequence severity and existing recovery mechanisms.
  5. Propose error reduction interventions (Poka-Yoke, improved display design).
- **Major HEI Techniques:**
  - **Action Error Mode Analysis (AEMA):** Examines mechanical actions (e.g., action omitted, wrong object, too late, in wrong order).
  - **Human HAZOP:** Applies standard HAZOP guidewords (*Omission, More, Less, Part Of, Reverse, Other Than*) to human operational actions.
  - **SHERPA Error Taxonomies:**
    - *Action Errors:* Operation omitted, performed incorrectly, wrong direction.
    - *Retrieval Errors:* Information not obtained or wrongly extracted.
    - *Checking Errors:* Check omitted, wrong check performed.
    - *Selection Errors:* Wrong selection made from control panel.
    - *Communication Errors:* Information miscommunicated or unacknowledged.

## 3. Differences / Examples
| HEI Method | Focus | Guidewords / Taxonomy |
| :--- | :--- | :--- |
| **Human HAZOP** | Process plant procedure steps | HAZOP guidewords (Omission, More, Less, Early, Late) |
| **SHERPA** | Human-machine interaction | 5 error classes (Action, Retrieval, Checking, Selection, Communication) |
| **AEMA** | Physical manipulatory tasks | Engineering failure modes adapted for physical actions |

## 4. Must Remember
- Reference text: **B. Kirwan**, *A Practical Guide to Human Reliability Assessment*.
- Task analysis is the indispensable starting foundation: without a rigorous HTA, error identification is incomplete.
