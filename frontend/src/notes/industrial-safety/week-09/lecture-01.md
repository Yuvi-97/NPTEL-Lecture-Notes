# Week 9 – Lecture 1: Human Error, Classification and Causes

## 1. Key Concepts
- **Human Error:** Any inappropriate or undesirable human decision or action that reduces, or has the potential to reduce, effectiveness, safety, or system performance.
- **Rasmussen’s SRK Framework:** Categorizes human cognitive behavior into three distinct hierarchical levels:
  1. *Skill-based behavior:* Highly automated, subconscious sensorimotor actions requiring minimal conscious attention (e.g., routine typing, cycling).
  2. *Rule-based behavior:* Applying familiar "if-then" rules or procedural guides to recognize known situations.
  3. *Knowledge-based behavior:* Conscious problem solving and analytical reasoning in novel, unfamiliar, or emergency situations.
- **Reference Landmark:** James Reason (1990), *Human Error*, Cambridge University Press.

## 2. Important Points
- **Basic Failure Typology (James Reason):**
  - **Unintended Actions (Execution Failures):**
    - *Slips:* Physical actions that do not go as intended due to attentional capture or distraction (e.g., pressing the wrong button).
    - *Lapses:* Memory failures or omissions (e.g., forgetting to open a bypass valve).
  - **Intended Actions (Planning Failures):**
    - *Mistakes:* The actions proceed exactly as planned, but the plan itself is flawed, inadequate, or wrong.
- **Human Contribution in Production Systems:** Modern plants rely on human operators for surveillance, exception handling, emergency diagnosis, and maintenance. Hence, human reliability directly bounds plant safety.

## 3. Differences / Examples
| Error Type | Intention of Action | Execution State | Typical Cognitive Level |
| :--- | :--- | :--- | :--- |
| **Slip** | Correct intention | Faulty physical execution | Skill-based |
| **Lapse** | Correct intention | Memory omission / Forgot step | Skill / Rule-based |
| **Mistake** | Flawed plan / Wrong intention | Correct physical execution of bad plan | Rule / Knowledge-based |

## 4. Must Remember
- Slips and lapses are **execution failures**; mistakes are **planning/judgment failures**.
- Rasmussen's SRK levels represent increasing cognitive workload: Skill-based (lowest effort) $\to$ Rule-based $\to$ Knowledge-based (highest cognitive effort).
