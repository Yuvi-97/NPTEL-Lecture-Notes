# Week 4 – Lecture 1: Bow-Tie Tool

## 1. Key Concepts
- **Bow-Tie Model:** An integrated risk evaluation diagram linking a Fault Tree (deductive, cause side) on the left to an Event Tree (inductive, consequence side) on the right through a central critical event.
- **Top / Center Event:** The central knot of the bow-tie representing the loss of control or initial hazard release (Top Event in FTA; Initiating Event in ETA).
- **Holistic Risk Visualization:** Combines basic component failures, safety barriers, and ultimate accident outcome states into a single unified framework.

## 2. Important Points
- **Structure of Bow-Tie:**
  - **Left Hand Side (Fault Tree):** Identifies threats and failure mechanisms propagating from basic events through logic gates to cause the Top Event.
  - **Center Knot:** The unwanted event (e.g., pipe rupture, toxic release, loss of containment).
  - **Right Hand Side (Event Tree):** Traces chronological paths through pivotal safety barriers to potential accident end states.
- **Barrier Classification:**
  - **Preventive Barriers (Left Side):** Controls or safeguards that prevent threats from triggering the Top Event.
  - **Mitigative / Reactive Barriers (Right Side):** Systems or actions that lessen damage or mitigate consequences after the Top Event occurs.
- **Core Value:** Provides operational safety managers with a clear visual map connecting component-level failures directly to catastrophic enterprise consequences.

## 3. Differences / Examples
| Component | Left Side (FTA) | Right Side (ETA) |
| :--- | :--- | :--- |
| **Logic Type** | Deductive (Root-cause analysis) | Inductive (Consequence progression) |
| **Safeguard Role** | **Preventive barriers** (stop release) | **Mitigative barriers** (limit damage) |
| **Starting Point** | Basic component failures | Central critical release event |
| **Outcome** | Triggers the Top Event | Terminal accident scenarios (End states) |

## 4. Must Remember
- Key reference authors: **Kumamoto & Henley** and **Modarres** (*Reliability Engineering and Risk Analysis*).
- Bow-tie bridges preventive maintenance (hardware reliability) with emergency response planning (disaster mitigation).
